# 私有持仓数据格式（private-data-format）

> 本文档是 **通用格式说明**，可提交到版本库；只包含字段说明与**虚拟示例**，不包含任何用户真实持仓。
> 真实持仓数据只允许存放于 `data/private/`（已被 .gitignore 忽略，绝不入库）。
> 最后更新：2026-08-19

## 1. 适用范围

- **私有持仓文件**：建议命名为 `data/private/positions.csv`，由用户手工维护（或从导入区整理而来）。
- **导入模板**：`data/imports/positions.example.csv` 提供同结构的可导入示例。
- 本格式同时用于导入模板与私有持仓文件，字段保持一致，便于 CSV 导入/导出闭环。

## 2. 文件要求

- 编码：**UTF-8**（无 BOM），与全项目文本编码一致。
- 第一行为表头，字段顺序与下表一致；空值直接留空（如数量待补充）。
- 数量缺失时工具应**明确显示缺失**，不能用历史缓存或其他来源伪装。

## 3. 字段说明

| 字段 | 必填 | 说明 | 示例 |
| --- | --- | --- | --- |
| symbol | 是 | 证券代码（含交易所后缀） | 000001.SZ / 00700.HK |
| market | 是 | 市场（SH / SZ / HK） | SZ |
| name | 是 | 证券名称 | 平安银行 |
| quantity | 是 | 持有数量（股/份），缺失留空 | 100 |
| cost_price | 是 | 成本价（元，含税费后的调整成本） | 10.500 |
| currency | 是 | 币种 | CNY / HKD |
| note | 否 | 备注（如 底仓 / 机动仓 / 做T） | 底仓 |

> 说明：`cost_price` 指含税费、手续费后的调整成本，由确定性代码计算；数值单位与 `currency` 一致（A股/ETF 为元，港股为港元）。

## 4. 虚拟示例（仅演示格式，非真实持仓）

```csv
symbol,market,name,quantity,cost_price,currency,note
000001.SZ,SZ,平安银行,100,10.500,CNY,虚拟示例
159915.SZ,SZ,创业板ETF,2000,1.850,CNY,虚拟示例
00700.HK,HK,腾讯控股,100,380.000,HKD,虚拟示例
```

## 5. 隐私边界

- 真实持仓（代码、数量、成本）**只允许**写入 `data/private/`（gitignore），不得出现在本文档、示例 CSV 或任何可提交文件中。
- 本文件中的示例必须使用虚拟数据；新增示例不得引用用户真实持仓代码。
- 券商导出原件（交割单等）落入 `data/imports/` 后被忽略，不入库；如需长期保存请放入 `data/private/`。
